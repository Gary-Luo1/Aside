# Cover Spec: aside（黑板教学风）

- Type: typography（标题为主视觉，板书感）
- Palette: dark（深色黑板底）
- Rendering: chalk（粉笔字 + 粉笔涂鸦）
- Text: title-subtitle
- Mood: bold（高对比，信息流醒目）
- Font: handwritten（楷体/手写板书）
- Aspect: 3:4（1080×1440，小红书/抖音竖版封面）
- Language: zh
- Backend: 程序化渲染（HTML + Playwright；经用户确认方案 c，AI 位图后端当前不可用）

## 文案（忠实于项目内容）

- Kicker：浏览器插件 · Aside
- Title：选中看不懂的词 / 不离开页面就懂了
- Subtitle：选中即得「专业解释 + 通俗解释」，阅读不再被打断
- 装饰元素：黄色粉笔框高亮「看不懂的词」、粉笔波浪下划线、星星涂鸦、下方小卡片（解释这个词 → 专业解释 / 通俗解释）

## 设计要点

- 深色黑板底 + 木框，粉笔颗粒感与轻微粉尘晕影
- 粉笔白为主文字，粉笔黄强调，薄荷绿与珊瑚粉点缀涂鸦
- 大量留白（40%+），标题居中偏上，装饰克制
- 无真实人物，无 AI 生成，文字逐字可控
