# Aside 安装与使用说明

> 对象：会自行配置 OpenAI 兼容接口的使用者。
> 版本：Chrome 桌面版 116 及以上，Manifest V3。

## 〇、安装前准备

- 电脑需要安装 **Chrome 桌面版 116 及以上**（Windows 或 macOS；手机上不能安装）。
- 需要安装 **Node.js**（建议 22），用来从本仓库构建扩展。
- 需要准备一个 **密钥**：向你的模型厂商（如 DeepSeek、通义、智谱、OpenAI 兼容服务等）申请，建议使用独立、可撤销、有限额的密钥。
- 构建完成后，加载整个 `extension/dist` 文件夹。

## 一、安装前需要知道的事

- 插件会在普通 HTTP/HTTPS 网页上运行，以便感知划词。代码只读取你**主动选中**并点击解释的那一小段文字（不含换行、不超过 60 字）。
- 测试连接时，Chrome 会请求允许访问**你填写的接口网站**，而不是在安装时索取所有网站的网络权限。同意后会向该接口发一次请求。
- 接口费用由对应厂商收取，与插件无关。建议使用**独立、可随时撤销、有限额**的密钥。
- AI 生成内容可能不准确，重要信息请进一步核对。
- 隐私说明：见仓库 [docs/privacy.md](privacy.md)。

## 二、安装步骤

1. 克隆本仓库并构建：

```bash
git clone https://github.com/Gary-Luo1/Aside.git
cd Aside
npm install
npm run extension:build
```

2. 打开 `chrome://extensions`。
3. 打开右上角“开发者模式”开关。
4. 点击左上角“加载已解压的扩展程序”，选择本项目的 `extension/dist` 文件夹。
5. 浏览器工具栏出现 Aside 图标即安装成功。
6. 在扩展管理页中，把 Aside 的开关保持“启用”；如果列表里显示“错误”或图标是灰色的，重新执行第 4 步并确认选择的是 `dist` 文件夹（不是外层文件夹）。

**安装完成确认（30 秒）**：

1. 打开任意普通网页（如一个教程页面）。
2. 用鼠标选中一个词，选区旁应出现“解释这个词”按钮。
3. 出现即安装成功。没出现时，检查扩展是否启用、页面是否是浏览器内部页面（如 `chrome://` 开头的页面不支持）。

## 三、配置 AI 接口

1. 点击浏览器工具栏的 Aside 图标，或右键图标选择“选项”，打开设置页。
2. 填写三项：
   - **接口地址**：你的模型厂商提供的地址，如 `https://api.example.com/v1`。须以 `https` 开头（本地调试可用 `http://localhost` 或 `http://127.0.0.1`），不要带查询参数或 `#`。请求会发到 `接口地址/chat/completions`。
   - **密钥**：你申请的密钥。
   - **模型名称**：如 `gpt-4o`、`qwen-plus` 等，以厂商实际名称为准。
3. 点击「测试连接」。若 Chrome 弹出网站访问提示，选择允许。成功后点击「保存配置」。修改接口地址、密钥或模型名称后，需要重新测试连接才能保存。

## 四、日常使用

1. 打开任意普通 HTTP/HTTPS 网页（浏览器内部页面、扩展商店页面、本地文件除外）。
2. 用鼠标选中一个看不懂的专业名词。
3. 选区附近出现不抢焦点的“解释这个词”按钮；复制或右键仍按网页原有行为执行，需要解释时再点击它。
4. 卡片显示两层解释：左边是**专业解释**，右边是**通俗解释**；窗口宽度约 719px 及以下时上下排列。
5. 内容较长时点“展开完整解释”；按 `Esc` 或点关闭按钮收起卡片，继续阅读。
6. 在解释正文里再划一个词，也可以继续解释。
7. 未配置接口、未授权接口地址、接口报错或超时时，卡片会给出可理解的提示，并可打开设置或原地重试。

## 五、隐私与删除

- 插件只把**你选中的文字**发送给你填写的接口地址；不保存查询历史。
- 你的密钥只保存在当前浏览器本地，不会上传到插件作者（本插件无自有服务器）。
- 想清除配置：打开设置页，点击“删除配置”，三项字段会一并移除。
- 停止使用：在 `chrome://extensions` 中关闭或移除该扩展即可。

## 六、已知限制

- 仅支持桌面 Chrome 116 及以上；Firefox、Safari 和手机浏览器暂不支持。
- 支持普通 HTTP/HTTPS 页面及其同源、跨源 iframe 中的 DOM 文本；iframe 内的入口和解释卡片显示在各自 frame 内。
- 浏览器内部页面、扩展商店页面、本地文件（`file://`）、PDF/特殊文档查看器、图片或 Canvas 文字、复杂编辑器专用选区，以及 `about:` / `data:` / `blob:` 等特殊来源 frame 无法使用。
- 若网页用 CSS 禁止选择文字，Aside 会在你于该处文字上按下鼠标时临时允许选中；拦复制脚本、图片/Canvas 上的字、PDF 查看器仍可能选不了。
- 如果 Chrome 网站访问权限未允许当前网站或 frame，插件不会绕过权限。
- 不对所有声称“OpenAI 兼容”的厂商做兼容保证，以“测试连接”结果为准。
- 接口调用按你的模型厂商计费；同一页面同一 frame 内新的解释会取消尚未完成的旧请求。
