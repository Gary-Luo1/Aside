# I am Fine 试用安装与使用说明

> 对象：参与首轮试用的朋友（无需工程背景）。
> 版本：MVP（Chrome 桌面版，Manifest V3）。

## 〇、安装前准备

- 电脑需要安装 **Chrome 桌面版**（Windows 或 macOS 均可；手机上不能安装）。
- 需要准备一个 **API Key**：向你的模型厂商（如 DeepSeek、通义、智谱、OpenAI 兼容服务等）申请，建议使用独立、可撤销、有限额的密钥。
- 你需要拿到扩展文件：整个 `extension/dist` 文件夹（如果朋友安装，请把该文件夹压缩后发给他，不要发源码）。

## 一、安装前需要知道的事

- 插件安装时，Chrome 会提示它“可以读取和更改你的所有网站数据”。这是因为插件需要在普通教程网页上感知你的鼠标选词；代码层面只读取你**主动选中**的那一小段文字，不读取段落、页面标题或网址。
- 插件需要一个你自己申请的 AI 接口（OpenAI 兼容格式）。接口费用由对应厂商收取，与插件无关。建议使用**独立、可随时撤销、有限额**的 API Key。
- AI 生成内容可能不准确，重要信息请进一步核对。

## 二、安装步骤

1. 在电脑上安装 Chrome 桌面版（Windows 或 macOS 均可）。
2. 打开 `chrome://extensions`。
3. 打开右上角“开发者模式”开关。
4. 点击左上角“加载已解压的扩展程序”，选择本项目的 `extension/dist` 文件夹。
5. 浏览器工具栏出现 I am Fine 图标即安装成功。
6. 在扩展管理页中，把 I am Fine 的开关保持“启用”；如果列表里显示“错误”或图标是灰色的，重新执行第 4 步并确认选择的是 `dist` 文件夹（不是外层文件夹）。

**安装完成确认（30 秒）**：

1. 打开任意普通网页（如一个教程页面）。
2. 用鼠标选中一个词，选区旁应出现蓝色的“解释这个词”按钮。
3. 出现即安装成功。没出现时，检查扩展是否启用、页面是否是浏览器内部页面（如 `chrome://` 开头的页面不支持）。

## 三、配置 AI 接口

1. 点击浏览器工具栏的 I am Fine 图标，或右键图标选择“选项”，打开设置页。
2. 填写三项：
   - **API Base URL**：你的模型厂商提供的接口地址，如 `https://api.example.com/v1`（以 https 开头）。
   - **API Key**：你申请的密钥。
   - **Model**：模型名称，如 `gpt-4o`、`qwen-plus` 等，以厂商实际名称为准。
3. 点击"测试连接"。成功后点击"保存配置"。

> 如果某个网页（例如开启了防复制的飞书文档）无法用鼠标选中文字，可以在设置页勾选
> "在不允许选择的网页上恢复划词选择"，保存后**刷新该网页**即可正常划词解释。
> 该开关只在页面禁止选择文本时生效，插件仍只发送你选中的短文本。
4. 修改任一字段后需要重新测试连接才能保存。

## 四、日常使用

1. 打开任意普通网页教程（浏览器内部页面、扩展商店页面除外）。
2. 用鼠标选中一个看不懂的专业名词。
3. 选区附近出现“解释这个词”按钮，点击它。
4. 卡片显示两层解释：左边是**专业解释**，右边是**通俗解释**；屏幕较窄时上下排列。
5. 内容较长时点“展开完整解释”；按 `Esc` 或点关闭按钮收起卡片，继续阅读。
6. 未配置接口、接口报错或超时时，卡片会给出可理解的提示，并可原地重试。

## 五、隐私与删除

- 插件只把**你选中的文字**发送给你填写的接口地址；不保存查询历史。
- 你的 API Key 只保存在当前浏览器本地，不会上传到插件方（本插件无自有服务器）。
- 想清除配置：打开设置页，点击“删除配置”，三项字段会一并移除。
- 停止试用：在 `chrome://extensions` 中关闭或移除该扩展即可；本地配置可自行删除。

## 六、试用反馈

试用中请重点观察：

- 配置接口是否顺利（是否有看不懂的步骤）；
- 选中名词后“就地解释”是否比复制去搜索/AI 对话框更省事；
- 双层解释是否足够让你继续读下去；
- 哪些词解释得不好（一词多义、解释错误等）。

发现“发送了选中文字以外内容”“密钥被泄露”或“网页被破坏”等问题，请立即停止试用并告知。

## 七、已知限制

- 仅支持桌面 Chrome；Firefox、Safari 和手机浏览器暂不支持。
- 浏览器内部页面、扩展商店页面、部分受限页面无法使用。
- 不对所有声称“OpenAI 兼容”的厂商做兼容保证，以“测试连接”结果为准。
- 接口调用按你的模型厂商计费；插件不会自动重复请求。
