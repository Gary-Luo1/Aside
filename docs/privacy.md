# Aside 隐私说明

本扩展（Aside）由你在自己的浏览器里安装和使用。扩展作者**没有自有服务器**，也不接收你的 API Key、选中文本或浏览历史。

最后更新：2026-08-20。

商店审核请使用本文件的 GitHub 地址：
https://github.com/Gary-Luo1/i-am-fine/blob/main/docs/privacy.md

## 我们处理什么数据

- **你配置的接口信息**：API Base URL、API Key、Model。只保存在当前浏览器的 `chrome.storage.local` 中，并限制为扩展的受信任上下文读取。
- **你主动选中并点击「解释这个词」的短文本**（1–60 个字符）：作为提示词发送到**你填写的** OpenAI 兼容接口。选词被放在固定分隔符内，扩展不会把它当作要执行的指令。
- **可选的「恢复划词」开关**：只保存在本地，用来决定是否在禁止选择的网页上恢复文本选择。

扩展**不**读取或发送：页面标题、网址、选区以外的段落、浏览历史、其他标签页内容。

## 数据发给谁

查询直接从浏览器发往你配置的 `API Base URL`。费用、日志与留存政策以该模型厂商为准。请只填写你信任的官方接口地址。

扩展会在测试连接时，向 Chrome 申请**仅该接口 origin** 的访问权限。未授权则不会发起请求。

## 页面权限

为了在普通网页上感知划词，内容脚本会在 HTTP/HTTPS 页面（含 iframe）中运行。解释卡片宿主只在该文档里真正出现选词后才创建，避免广告像素框一加载就挂 UI。页面上的卡片字体以内联方式加载，**不**通过 `web_accessible_resources` 暴露给网页探测。

「恢复划词」默认关闭。开启后，仅在你按下鼠标的被 CSS 禁止选择的文本区域恢复选择，不复制、不发送未选中内容。

## 删除

在设置页点击「删除配置」可清除接口信息。关闭或卸载扩展即可停止处理。清除浏览器本机数据也会删除本地配置。
