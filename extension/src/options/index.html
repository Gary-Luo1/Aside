设置

接口设置

配置你的 OpenAI 兼容接口。配置只保存在当前浏览器本地，请求直接发往你填写的接口地址。

以 https 开头；本地调试可用 http://localhost 或 http://127.0.0.1。

本地保存不等于操作系统级加密，建议使用独立、可撤销、有限额的密钥。

部分网页（如开启防复制的飞书文档）会禁止选中文字，导致无法划词解释。 开启后，扩展只在你尝试划选文字时恢复该区域的选择能力；仍只发送你选中的短文本， 不会复制或发送未选中内容。修改后刷新已打开的页面生效。

隐私

隐私说明

  • 插件只发送你主动选中的文本，不读取所在段落、页面标题或网址。
  • 请求直接发往你填写的 API Base URL，由对应模型厂商处理。
  • 插件不保存查询历史；API Key 仅存于当前浏览器本地。
  • 删除配置会同时移除 API Base URL、API Key 和 Model 三个字段。
